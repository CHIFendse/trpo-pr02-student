# Практическая работа №2. CSS, адаптивная верстка и SCSS

Адаптивный каталог учебных товаров. Стили написаны на SCSS и компилируются в `css/styles.css`.

## Технологии

- HTML5
- SCSS (Dart Sass)
- CSS Grid и Flexbox

## Требования

- Node.js 18 или новее (вместе с ним устанавливается npm)

## Запуск

1. Склонировать репозиторий.
2. Открыть `index.html` в браузере (двойной клик или Live Server в VS Code).

Готовый `css/styles.css` уже лежит в репозитории, поэтому для просмотра страницы сборка не нужна.

## Сборка SCSS

Команды выполняются в папке проекта. При первом запуске `npx` скачает Sass автоматически.

Разовая сборка:

```
npx sass scss/styles.scss css/styles.css --no-source-map
```

Режим наблюдения (CSS пересобирается при каждом сохранении SCSS):

```
npx sass --watch scss/styles.scss css/styles.css --no-source-map
```

## Структура проекта

```
index.html              страница каталога
scss/
  styles.scss           главный файл, подключает остальные части
  _variables.scss       переменные: цвета, отступ, радиус, ширина контейнера, breakpoint
  _mixins.scss          функция space() и миксины container, focus-ring
  _base.scss            базовые стили страницы
  _layout.scss          шапка, сетка страницы, сетка каталога, подвал, медиазапросы
  _components.scss      кнопка, badge, карточка, панель фильтров, информационный блок
css/styles.css          скомпилированный CSS
data/                   catalog.csv, theme.json
images/                 product-01.svg, product-02.svg, product-03.svg
dataset/                исходный dataset задания
```

## Использованные файлы dataset

- `catalog.csv` — 18 карточек товаров (название, категория, цена, рейтинг). Данные перенесены вручную.
- `theme.json` — значения `accent`, `surface`, `background`, `text`, `radius` (14px) и `space` (16px) перенесены в `_variables.scss`.
- `product-01.svg` — изображение для категории «Книги», `product-02.svg` — «Курсы», `product-03.svg` — «Инструменты».

## Структура страницы

- шапка `header` с навигацией;
- панель фильтров `aside` (категория, цена, сортировка);
- область карточек `section#catalog`;
- информационный блок `section#info` (количество товаров, категорий, диапазон цен, средний рейтинг);
- подвал `footer`.

Панель фильтров и каталог размещены через Grid (`.layout`), карточки — через Grid (`.catalog`), содержимое карточки — через Flexbox.

## Что сделано по шагам

- **Шаг 8. Вложенность.** Элементы компонентов описаны внутри блока через `&__title`, `&__body`, а состояния — через `&:hover`. Глубина вложенности не больше трёх уровней.
- **Шаг 9. Mixin.** `container` задаёт ограничивающий контейнер и используется в `.container`. `focus-ring` задаёт рамку фокуса и используется для ссылок, кнопок и полей формы. Раньше эти свойства пришлось бы повторять в нескольких местах.
- **Шаг 10. Функция.** `space($count)` возвращает `$space * $count`, например `space(2)` = 32px. Все отступы считаются от одной переменной.
- **Шаг 12. Адаптивная сетка.** На широком экране 3 колонки карточек, на планшете 2, на телефоне 1.
- **Шаг 13. Два breakpoint.**
  - `768px` — меняется основная раскладка: панель фильтров переносится над карточками.
  - `480px` — меняется плотность карточек (одна колонка) и шапка (навигация под логотипом).

## SCSS-переменная и CSS custom property

- SCSS-переменная (`$color-accent`) существует только во время компиляции. В итоговом CSS вместо неё стоит готовое значение, и браузер о ней ничего не знает.
- CSS custom property (`--color-accent`) остаётся в CSS, браузер читает её при работе страницы. Её можно поменять через JavaScript или переопределить внутри другого селектора.

## Зачем нужны partial-файлы

Файлы с подчёркиванием (`_variables.scss` и другие) не компилируются отдельно, а подключаются в `styles.scss` через `@use`. Так стили разделены по назначению: переменные отдельно, раскладка отдельно, компоненты отдельно. Нужный код проще найти и изменять.

## Ошибочное состояние

У всех изображений есть `alt`: если картинка не загрузится, вместо неё будет показано название товара. В поле «Цена до» стоят ограничения `min` и `max`, поэтому браузер не примет значение вне диапазона цен каталога.

## Проверка

1. Открыть DevTools → Responsive Mode.
2. На ширине 1440px — фильтры слева, 3 колонки карточек.
3. На ширине 768px — фильтры над карточками, 2 колонки.
4. На ширине 375px — 1 колонка, горизонтальной прокрутки нет.
5. Поменять `$color-accent` в `_variables.scss`, выполнить разовую сборку — изменится цвет всех кнопок и бейджей.
